A Windows Forms application "Smart-Med Tracking System" 
written in C# using (.NET Core) 
that performs CRUD 
operations using SQL database
which is connected to C#, accessible by the forms.

## Features
- Create, read, update and delete records
- Data stored in a SQL database

## Technologies
C#, .NET Core, SQL

## How to run
1. Clone the repo
2. Open the project in Visual Studio
3. Run the project

## What I learned
Database connections, CRUD operations and basic error handling.
